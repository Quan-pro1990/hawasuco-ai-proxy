Phần mềm dùng chung máy chủ IIS với phần mềm Quản lý thất thoát nước. Nếu cổng 8080 đã có site Thất thoát nước, script tự cài thành ứng dụng con /taisan của site đó (cùng địa chỉ, cùng chứng chỉ): https://<máy chủ>:8080/taisan/. Nếu cổng chưa có site nào, script tạo site riêng QuanLyTaiSan với địa chỉ https://<máy chủ>:8080/.

Máy chủ đang chạy phần mềm Thất thoát nước? Máy đó đã có IIS và Hosting Bundle — bỏ qua mục 3, 4 và mục 8 (cổng đã mở), làm thẳng mục 5 → 6 → 7 → 10.

3. Cài IIS (nếu máy chủ chưa có)

Kiểm tra: mở Start → gõ inetmgr. Mở được "Internet Information Services (IIS) Manager" là đã có IIS → sang mục 4.

Windows Server

Cách 1 — PowerShell (bấm chuột phải Start → Windows PowerShell (Admin)):

Install-WindowsFeature -Name Web-Server -IncludeManagementTools

Cách 2 — Server Manager: Manage → Add Roles and Features → Next đến Server Roles → tích Web Server (IIS) → Add Features → Next (giữ các mục mặc định, có Management Tools → IIS Management Console) → Install.

Windows 10 / 11

Enable-WindowsOptionalFeature -Online -All -FeatureName IIS-WebServerRole,IIS-WebServer,IIS-ManagementConsole

Không cần ASP.NET 4.x, CGI, WebDAV hay tính năng IIS nào khác.

4. Cài ASP.NET Core Hosting Bundle

  1. Trên máy có Internet, vào https://dotnet.microsoft.com/download/dotnet → chọn bản mới nhất có nhãn LTS (vd .NET 10) → cột ASP.NET Core Runtime → mục Windows → bấm Hosting Bundle để tải file dotnet-hosting-…-win.exe.
  2. Chép file sang máy chủ, nhấp đúp → Install. Phải cài IIS (mục 3) trước; nếu cài Hosting Bundle trước IIS thì chạy lại file cài, chọn Repair.
  3. Khởi động lại IIS — mở Command Prompt (Admin): 
    net stop was /y
net start w3svc
  4. Kiểm tra: IIS Manager → bấm tên máy chủ → Modules → có dòng AspNetCoreModuleV2.

5. Chép gói lên máy chủ

  1. Nếu nhận gói dạng file .zip tải từ Internet / email: trước khi giải nén bấm chuột phải file zip → Properties → tích Unblock → OK (để Windows không chặn file .exe, .ps1 bên trong).
  2. Giải nén / chép cả thư mục gói vào máy chủ, vd C:\CaiDat\QuanLyTaiSan-GoiCaiDat-IIS\. Đây chỉ là thư mục chứa bộ cài — chương trình sẽ được chép sang C:\inetpub\QuanLyTaiSan.
  3. Giữ lại thư mục này để sau dùng KiemTra.bat, DatLaiMatKhauQuanTri.bat, SaoLuu-DatLich.bat.

6. Chạy cài đặt CaiDat-IIS.bat

  1. Nhấp đúp CaiDat-IIS.bat → Windows hỏi quyền quản trị → Yes. Một cửa sổ dòng lệnh mở ra và chạy các bước (đừng đóng cho tới khi hiện "Press any key").
  2. Script tự làm, mỗi bước in một dòng == …:
    • Kiểm tra IIS + ASP.NET Core Module V2 (thiếu thì báo lỗi và dừng — xem mục 3, 4).
    • Xem cổng 8080: đã có site (vd Thất thoát nước) → cài thành ứng dụng con /taisan; chưa có → tạo site QuanLyTaiSan https cổng 8080.
    • Chép chương trình vào C:\inetpub\QuanLyTaiSan; tạo app pool QuanLyTaiSan (No Managed Code, không tự tắt khi rảnh).
    • Tạo thư mục dữ liệu C:\QuanLyTaiSanData, chỉ app pool được ghi.
  3. Lần cài đầu script hỏi tài khoản quản trị của phần mềm: 
    Tên đăng nhập quản trị [admin]:          ← Enter để dùng "admin", hoặc gõ tên khác
Mật khẩu (ít nhất 6 ký tự): ********
Nhập lại mật khẩu: ********
    Ghi lại tên và mật khẩu này — dùng để đăng nhập trang web lần đầu.
  4. Site riêng: script tạo chứng chỉ tự ký 10 năm (hoặc dùng chứng chỉ thật, xem mục 9), gắn vào cổng 8080, mở tường lửa Windows cổng 8080.
  5. Cuối cùng gọi thử và in khung xanh: 
    ==============================================================
 ĐÃ CÀI XONG máy chủ Quản lý tài sản — HTTPS cổng 8080
 Địa chỉ:              https://<tên miền hoặc IP công cộng của máy chủ>:8080/taisan/
 Mã nhận dạng:         1A2B-3C4D-5E6F-7A8B
 Dữ liệu:              C:\QuanLyTaiSanData
==============================================================
    Có dòng vàng "Gọi thử CHƯA thành công" → xem mục 14.

7. Kiểm tra sau khi cài

  1. Trên máy chủ: mở trình duyệt vào https://localhost:8080/taisan/ (site riêng: https://localhost:8080/). Chứng chỉ tự ký → trình duyệt cảnh báo → Advanced / Nâng cao → Continue / Tiếp tục. Thấy trang đăng nhập "Quản lý tài sản" là chạy.
  2. Đăng nhập bằng tài khoản quản trị vừa tạo.
  3. Máy tính khác trong công ty: https://<IP nội bộ máy chủ>:8080/taisan/.
  4. Điện thoại dùng 4G (tắt Wi-Fi công ty): https://<tên miền hoặc IP công cộng>:8080/taisan/ — được thì cổng ra Internet đã thông (mục 8).
  5. Bất cứ lúc nào: nhấp đúp KiemTra.bat → "OK: máy chủ Quản lý tài sản trả lời bình thường."

8. Mở cổng ra Internet (dùng ngoài công ty)

  • Tường lửa Windows: script đã thêm quy tắc Quan ly tai san (IIS) cho cổng 8080 (cài làm ứng dụng con thì cổng đã mở cho site Thất thoát nước).
  • Router / tường lửa công ty: chuyển cổng (NAT / Port Forwarding / Virtual Server) TCP 8080 từ IP công cộng tới IP nội bộ của máy chủ. Chỉ mở cổng này; không mở 3389 (Remote Desktop) ra Internet.
  • Tên miền (khuyên dùng): tạo bản ghi DNS loại A, vd taisan.capnuochaugiang.vn → IP công cộng. Dễ nhớ, in lên tem không đổi khi đổi IP, và cần để lấy chứng chỉ thật (mục 9).
  • Chỉ dùng trong mạng nội bộ / qua VPN: bỏ qua bước router, dùng IP nội bộ hoặc tên máy.
Không đặt Cloudflare Tunnel / proxy thay chứng chỉ trước IIS khi máy chủ còn phục vụ phần mềm Thất thoát nước trên máy tính (phần mềm đó kiểm tra mã nhận dạng chứng chỉ).

9. Chứng chỉ HTTPS

CáchƯu / nhược
Chứng chỉ tự ký (script tự tạo)Không tốn tiền, dùng ngay. Mỗi thiết bị phải bấm "Nâng cao → Tiếp tục" lần đầu; trình duyệt hiện cảnh báo "Không bảo mật"; một số điện thoại không cho "Thêm vào màn hình chính" như ứng dụng. Camera quét QR vẫn chạy sau khi bấm Tiếp tục.
Chứng chỉ thật (Let's Encrypt miễn phí, hoặc mua)Khuyên dùng khi đưa vào sử dụng chính thức: không cảnh báo, điện thoại cài như ứng dụng. Cần tên miền (mục 8).

Lấy chứng chỉ Let's Encrypt bằng win-acme

  1. Tải win-acme tại https://www.win-acme.com, giải nén vào C:\win-acme, chạy wacs.exe bằng quyền quản trị.
  2. Chọn tạo chứng chỉ cho site IIS đang dùng cổng 8080 (site ThatThoatNuoc hoặc QuanLyTaiSan), nhập tên miền ở mục 8. Let's Encrypt cần kiểm tra tên miền qua cổng 80 (mở tạm cổng 80 tới máy chủ) hoặc qua bản ghi DNS.
  3. win-acme cài chứng chỉ vào máy, gắn vào binding https của site và tự gia hạn (tạo sẵn tác vụ trong Task Scheduler).
  4. Kiểm tra: mở https://<tên miền>:8080/taisan/ — không còn cảnh báo.

Dùng chứng chỉ đã mua

Nhập file .pfx vào Local Computer → Personal (chạy certlm.msc → Personal → All Tasks → Import). Lấy Thumbprint (nhấp đúp chứng chỉ → Details). Site riêng: chạy CaiDat-IIS.bat -ChungChi <thumbprint>. Cài làm ứng dụng con: đổi chứng chỉ trên binding https cổng 8080 của site cha trong IIS Manager (Sites → site → Bindings → https → SSL certificate).

10. Thiết lập ban đầu trên web

  1. Đăng nhập tài khoản quản trị → Cài đặt:
    • Địa chỉ in trong mã QR = địa chỉ điện thoại dùng để vào, vd https://taisan.capnuochaugiang.vn:8080/taisan. Đặt trước khi in tem — tem in ra chứa địa chỉ này.
    • Tên công ty, địa danh, người lập biểu, kế toán trưởng, giám đốc (in trên biên bản kiểm kê).
  2. Danh mục: sửa loại tài sản (tiền tố mã, số năm khấu hao, chu kỳ bảo dưỡng, thông số kỹ thuật riêng) và đơn vị quản lý cho đúng công ty — mỗi đơn vị thuộc khối Các đội cấp nước hoặc Khối văn phòng.
  3. Tài khoản → Thêm tài khoản cho từng người:
    QuyềnDành cho
    Chỉ xemLãnh đạo, kế toán xem số liệu
    Nhân viên kiểm traCông nhân vận hành, tổ sửa chữa, tổ kiểm kê (có thể giới hạn 1 đội)
    Cán bộ quản lý tài sảnPhòng Kế toán / Kỹ thuật phụ trách tài sản
    Quản trị1–2 người phụ trách tin học
  4. Nhập từ Excel: tải file mẫu hoặc dùng file sổ tài sản cố định đang có → xem trước → nhập.
  5. In tem QR: in thử vài tem, dùng điện thoại quét thử, rồi mới in hàng loạt.

Đặt lịch sao lưu hằng đêm

  1. Nhấp đúp SaoLuu-DatLich.bat (tự xin quyền quản trị).
  2. Nhập thư mục dữ liệu (Enter = giữ mặc định), thư mục đích trên ổ khác (vd E:\SaoLuu\QuanLyTaiSan) và giờ chạy (mặc định 23:30).
  3. Script tạo tác vụ QuanLyTaiSan - Sao luu du lieu trong Task Scheduler, chạy thử ngay một lần và in kết quả.
  4. Mỗi đêm chép các tệp mới / thay đổi sang <đích>\HienTai (không xoá gì ở đích); nhật ký: <đích>\saoluu.log.
Nên chép tiếp bản sao lưu ra máy khác / ổ cứng rời / NAS định kỳ (hư ổ, ransomware). Thư mục đích là ổ mạng (\\may-khac\SaoLuu): tác vụ chạy bằng tài khoản SYSTEM nên phải cấp quyền ghi thư mục chia sẻ cho tài khoản máy TENMIEN\TENMAYCHU$, hoặc sao lưu ra ổ cục bộ rồi chép tiếp. Thư mục sao lưu có ảnh và mật khẩu đã băm — chỉ cho quản trị đọc.

Khôi phục

  1. IIS Manager → Application Pools → QuanLyTaiSan → Stop (hoặc %windir%\system32\inetsrv\appcmd stop apppool /apppool.name:QuanLyTaiSan).
  2. Đổi tên thư mục dữ liệu hiện tại (vd C:\QuanLyTaiSanData_hong), chép bản sao lưu về đúng tên cũ.
  3. Chỉ cần lấy lại danh mục / tài sản của 1 ngày trước: chép SaoLuu\taisan_yyyy-MM-dd.xml đè lên taisan.xml.
  4. Chạy lại CaiDat-IIS.bat (cấp lại quyền thư mục cho app pool) hoặc Start app pool.

13. Cập nhật phiên bản mới, gỡ cài đặt

  • Cập nhật: nhận gói mới → chép đè lên thư mục gói cũ → nhấp đúp CaiDat-IIS.bat. Script dừng app pool, thay chương trình, khởi động lại; không mất dữ liệu, không hỏi lại mật khẩu. Người dùng chỉ cần tải lại trang (Ctrl+F5 trên máy tính).
  • Tự tạo gói mới từ mã nguồn: trên máy Windows có mã nguồn chạy build.bat → thư mục QuanLyTaiSan-GoiCaiDat-IIS và file zip mới.
  • Gỡ: nhấp đúp GoCaiDat.bat — xoá site / ứng dụng, app pool, chương trình, quy tắc tường lửa; giữ nguyên thư mục dữ liệu (tự xoá tay nếu chắc chắn không dùng nữa). Cài làm ứng dụng con thì site Thất thoát nước không bị ảnh hưởng.
