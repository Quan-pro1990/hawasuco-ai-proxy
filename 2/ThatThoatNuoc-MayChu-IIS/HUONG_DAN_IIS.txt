CÀI WEBSITE "QUẢN LÝ THẤT THOÁT NƯỚC" TRÊN IIS — HTTP CỔNG 80
================================================================

  Trình duyệt (máy tính, điện thoại)  ─┐
  App Android                          ─┼─ HTTP cổng 80 ─>  IIS  ─>  ThatThoatNuoc.exe (chế độ máy chủ)  ─>  dữ liệu C:\ThatThoatNuocData
  Phần mềm trên máy tính (đồng bộ)     ─┘

Dữ liệu nằm trên máy chủ (chạy 24/7, tự sao lưu mỗi ngày). Ai có tài khoản chỉ cần mở http://<máy chủ>/ bằng trình duyệt,
không cài gì thêm; điện thoại Android có thể cài app. Không cần chứng chỉ, không cần ZeroTier.

Cần có trên máy chủ:
  - IIS (Web Server) — bật trong Server Manager → Add Roles and Features → Web Server (IIS);
  - ASP.NET Core Hosting Bundle 9.0 (bản 6 trở lên đều được): https://dotnet.microsoft.com/download/dotnet/9.0
    → mục "ASP.NET Core Runtime" → Windows → "Hosting Bundle". Cài SAU khi đã bật IIS (cài trước thì chạy lại bộ cài, chọn Repair);
  - .NET Framework 4.x (có sẵn trong Windows Server 2012 R2 trở lên).
Script không cài thêm gì.


CÀI TỰ ĐỘNG (khuyên dùng)
-------------------------
1. Chép cả thư mục này sang máy chủ IIS.
2. Nhấp đúp CaiDat-IIS.bat -> đồng ý quyền quản trị. Script sẽ:
   - kiểm tra IIS có ASP.NET Core Module V2 (trong Hosting Bundle);
   - chép chương trình vào C:\inetpub\ThatThoatNuoc, tạo thư mục dữ liệu C:\ThatThoatNuocData (chỉ app pool được ghi);
   - hỏi tên + mật khẩu tài khoản QUẢN TRỊ (lần đầu);
   - nếu cổng 80 CHƯA có site: tạo site "ThatThoatNuoc" http cổng 80  →  địa chỉ  http://<máy chủ>/
     nếu cổng 80 ĐÃ có site (thường là "Default Web Site" — trang chào của IIS): cài thành ứng dụng con /thatthoat
     →  địa chỉ  http://<máy chủ>/thatthoat/
       Muốn phần mềm ở ngay http://<máy chủ>/ :  CaiDat-IIS.bat -ThaySiteMacDinh   (dừng Default Web Site, không xoá)
       hoặc dùng tên miền riêng:                 CaiDat-IIS.bat -TenMien thatthoat.tenmien.vn
   - mở tường lửa cổng 80, gọi thử, in ra các địa chỉ truy cập (IP trong mạng nội bộ, tên máy).
3. Mở địa chỉ bằng trình duyệt (máy tính hoặc điện thoại), đăng nhập tài khoản quản trị.
   Thẻ "Quản trị": tạo tài khoản cho người dùng — Chỉ xem / Nhập đồng hồ cấp 1 (có thể giới hạn 1 đội) / Admin.
4. Điện thoại: mở địa chỉ bằng Chrome (menu ⋮ → "Thêm vào màn hình chính"), hoặc cài app Android:
   tải tại  http://<máy chủ>/tai-app  (nếu gói có file APK; lần đầu Android hỏi "cho phép cài ứng dụng không rõ nguồn" → cho phép),
   mở app, nhập địa chỉ máy chủ (vd 192.168.1.10  hoặc  tenmien.vn/thatthoat), đăng nhập.
5. Phần mềm trên máy tính (nhập số liệu thất thoát, cấu trúc mạng lưới, kế hoạch, vùng DMA…):
   Cài đặt -> Máy chủ dữ liệu -> "Kết nối máy chủ…": nhập địa chỉ như trên, đăng nhập quản trị.
   Lần đầu chọn "Đưa dữ liệu trên máy này lên máy chủ".

Truy cập từ ngoài công ty (internet): trên router chuyển cổng 80 (TCP) về IP của máy chủ, rồi dùng IP công cộng
hoặc tên miền trỏ về IP đó.

Tuỳ chọn khi chạy (mở cmd tại thư mục này):
   CaiDat-IIS.bat -Cong 8081                       dùng cổng khác 80 (địa chỉ thành http://<máy chủ>:8081/)
   CaiDat-IIS.bat -DuLieu D:\ThatThoatNuocData     đặt thư mục dữ liệu khác
   CaiDat-IIS.bat -DuongDan /thatthoat             tên ứng dụng con (khi cổng 80 đã có site khác)
   CaiDat-IIS.bat -TenMien thatthoat.tenmien.vn    site riêng theo tên miền, dùng chung cổng 80 với site khác
                                                   (khi đó phải vào bằng đúng tên miền này, không vào bằng IP)
   CaiDat-IIS.bat -ThaySiteMacDinh                 dừng "Default Web Site" để phần mềm ở ngay http://<máy chủ>/
   CaiDat-IIS.bat -DatMatKhau                      đặt lại mật khẩu tài khoản quản trị
   CaiDat-IIS.bat -KiemTra                         gọi thử máy chủ
   CaiDat-IIS.bat -GoBo                            gỡ site / ứng dụng (giữ nguyên thư mục dữ liệu; chạy lại Default Web Site nếu đã dừng)
Lần chạy sau script nhớ lựa chọn cũ (cổng, tên miền, thư mục dữ liệu, ứng dụng con), không cần ghi lại tham số.

CẬP NHẬT PHIÊN BẢN MỚI: tạo lại gói trong phần mềm mới (Cài đặt → Máy chủ dữ liệu → Tạo gói cài IIS…), chép sang máy chủ,
chạy lại CaiDat-IIS.bat (không mất dữ liệu, không hỏi lại mật khẩu).

NÂNG CẤP TỪ BẢN CŨ (HTTPS cổng 8080, có "mã nhận dạng" chứng chỉ): chạy CaiDat-IIS.bat của gói này trên máy chủ đó.
Script giữ nguyên dữ liệu và tài khoản, chuyển site sang HTTP cổng 80, gỡ chứng chỉ tự ký và ứng dụng con cũ ở cổng 8080.
   - Phần mềm trên máy tính: thay bằng ThatThoatNuoc.exe mới (bản cũ chỉ kết nối được HTTPS). Lần mở đầu tiên phần mềm tự
     chuyển địa chỉ cũ "x:8080" sang "x" (cổng 80); nếu vẫn báo mất kết nối thì Cài đặt → Máy chủ dữ liệu →
     "Kết nối lại / đổi máy chủ…" và nhập địa chỉ mới.
   - Điện thoại: GỠ app Android cũ rồi cài app mới từ http://<máy chủ>/tai-app (app cũ chỉ chạy HTTPS, khác chữ ký nên
     không cài đè được).
   - Nếu router đang chuyển cổng 8080 thì đổi sang cổng 80.


BẢO MẬT
-------
HTTP không mã hoá: mật khẩu và số liệu đi qua mạng ở dạng thường. Nên dùng trong mạng nội bộ công ty hoặc qua VPN.
Khi có chứng chỉ thật cho tên miền (vd của nhà cung cấp tên miền, Let's Encrypt), thêm binding https cho site trong
IIS Manager (Sites → ThatThoatNuoc → Bindings… → Add → https) — trang web, app Android và phần mềm máy tính đều dùng được
địa chỉ https://… mà không cần sửa gì.
Mật khẩu trên máy chủ được băm (PBKDF2); đăng nhập sai 5 lần bị khoá 10 phút; phiên đăng nhập hết hạn sau 60 ngày không dùng.


KHI CÓ LỖI
----------
- Không vào được từ máy khác: trên máy chủ chạy -KiemTra; kiểm tra tường lửa mạng / router đã mở cổng 80 tới máy chủ.
- Mở http://<máy chủ>/ ra trang chào của IIS: phần mềm đang là ứng dụng con → dùng http://<máy chủ>/thatthoat/
  (hoặc cài lại với -ThaySiteMacDinh).
- Lỗi 500.19: Hosting Bundle chưa cài đúng → chạy lại bộ cài Hosting Bundle, chọn Repair, rồi chạy  iisreset.
- Lỗi 502.5 / 500.30: xem C:\ThatThoatNuocData\loi-khoi-dong.txt và thư mục NhatKy.
- App Android báo "Không kết nối được máy chủ": thử mở cùng địa chỉ bằng Chrome trên điện thoại. Trong mạng nội bộ dùng
  IP LAN của máy chủ (vd 192.168.x.x); ngoài internet dùng IP công cộng / tên miền.
